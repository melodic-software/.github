# Support

A repository's own `SUPPORT.md` or README, listing additional support channels, overrides this org-wide default.

Need help with a melodic-software project?

- **Bugs, feature requests, and tasks**: open an issue using the issue templates.
- **Security issues**: see [SECURITY.md](SECURITY.md); do not report them publicly.
- **Anything else**: email **<support@melodicsoftware.com>**.
